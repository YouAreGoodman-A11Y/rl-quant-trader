这是一个专注于探索**强化学习 (Reinforcement Learning)** 在多因子量化选股与动态仓位控制中应用的实验性架构。

---

## 📌 研究背景与核心痛点

传统多因子模型主要解决“预测横截面收益（Alpha）”的问题，但往往忽略了：
1. **组合构建（Portfolio Construction）的割裂**：预测出了分数，如何分配资金？
2. **交易摩擦（Friction）**：高换手带来的滑点和手续费往往吃掉大量账面收益。
3. **宏观避险**：在系统性风险来临时，缺乏主动的仓位管控能力。

本仓库致力于使用强化学习（PPO 算法），将“因子预测”与“交易执行”融合在一个端到端（End-to-End）的动作空间中。

---

## ⚖️ 基准策略对比 (Baseline Strategy V3)

在评估所有强化学习模型的有效性时，我们统一采用 **V3 静态策略 (Real Cash Ledger)** 作为对比靶点和及格线。只有在极其严苛的真实扣费环境下击败该基准，RL 模型才具有实盘价值。

### 真实且残酷的 V3 交易规则（源码逻辑）
1. **防穿越与流动性过滤**：
   * **剔除绝对头部陷阱**：放弃预测排名全市场前 1% (`SKIP_TOP_PCT = 0.01`) 的极端股票，防范缩量暴涨导致的不具实盘容量的假 Alpha。
   * **剔除涨停停牌**：无法买入 T+1 开盘即一字涨停、ST 或停牌的股票。
   * **无法强平跌停**：T+1 遇到一字跌停或停牌的股票，无论指标多差，被强制锁定无法卖出。
2. **买卖阈值与仓位**：
   * **买入**：资金池一旦有余钱，立刻分配给符合上述过滤条件且排名最靠前的股票，目标凑齐并维持 **400 只**持仓。
   * **卖出**：持仓股票的预测分数下滑，跌出全市场 **前 40%** (`SELL_RANK_PCT = 0.4`) 时，无条件斩仓卖出。
3. **极高摩擦测试环境**：
   * 采用实盘级综合费率（买入 0.08%，卖出含印花税 0.18%），每次换手面临千分之 2.6 的双边极高损耗。采用 T+1 开盘买入、T+2 开盘进行收益结算。

### 传统规则的致命痛点（RL 的破局点）
* **硬抗暴跌**：固定满仓 400 只，遇到千股跌停或单边熊市时毫无防守能力，最大回撤惨烈。
* **边界无效换手**：股票在排名 39% 和 41% 之间反复徘徊时，触发机械的“当天止损，隔天买回”。高达千分之 2.6 的双边摩擦，会导致极度恐怖的隐性亏损，迅速吞噬超额收益。

## 🎯 动作空间演进与改进逻辑 (Action Space Evolution)

本架构的动作空间（Action Space）经历了多次迭代。我们的核心逻辑是**通过强化学习控制关键阈值**，而非让 RL 直接挑选个股，以此在降维的同时赋予策略灵活性。

### 🔹 V4 阶段：全局仓位控制 (Cash_Ratio 控制)
*   **动作空间 (`action_space`)**：`shape=(1,)`，输出单变量 `Cash_Ratio` $\in [0, 1]$。
*   **改进逻辑**：保留 V3 基准的选股逻辑（卖出跌出前 40% 的股票，买入最靠前的股票），但打破了 V3 的**满仓死板**。RL 的动作直接决定**当前可用现金中，有多少比例允许用来买入股票**。
*   **突破点**：如果 RL 嗅到宏观指标走坏，它可以输出 `0.0`，停止一切买入动作；随着旧有持仓自然跌出 40% 被卖出，组合会被动降仓至空仓，从而完美规避系统性熊市，大幅降低最大回撤。

### 🔹 V5 阶段：汰除容忍度动态控制 (Sell_Rank_Pct 控制)
*   **动作空间 (`action_space`)**：`shape=(1,)`，输出单变量 `Sell_Rank_Pct` $\in [0, 1]$。
*   **改进逻辑**：不再锁死 40% 的卖出线，而是将卖出阈值的决定权交给 RL，策略保持满仓运行。RL 根据市场状态输出一个 0 到 1 之间的动态阈值。
*   **突破点**：在“换手率惩罚”的强力约束下，RL 学会了“装死”——在震荡市中主动输出较高的 `Sell_Rank_Pct`（例如 0.6 或更高），以极高的容忍度持有那些短暂滑落的股票，从而避免了 V3 基准在 40% 边界处“高抛低吸”带来的毁灭性摩擦损耗。

### 🔹 V6 / V6.1 阶段：动态买入区间滑窗 (Buy_Start_Pct / Buy_Range 控制)
*   **动作空间 (`action_space`)**：
    *   **V6_buyrange**: `shape=(2,)`，同时控制买入起点比例 (`start_pct`) 和买入宽度比例 (`width_pct`)。
    *   **V6_1_slide**: `shape=(1,)`，固定持仓 150 只的宽度，仅控制买入起点 (`slide_pct`)。
*   **改进逻辑**：打破了 V3 永远只买前 1% 到头部的局限。RL 可以决定不买最头部的高波股票，而是选择买入排名在 10%~20% 甚至更靠后的次优防御性标的。
*   **突破点**：实现了真正的“风格切换”。RL 学会在牛市激进时顶格买最前排龙头，在退潮期主动将滑窗后移，买入波动率更小、排名偏后的标的进行防守。

### 🔹 V8/V9/V10 阶段：复合控制与反乌龟策略 (DSR/DSOR/Anti-Turtle)
*   **动作空间**：回归 `shape=(1,)` 或整合控制，引入了针对做空（Short）和多空对冲（Long-Short）的尝试，并在 `V10 (Anti-Turtle)` 中引入了对“缩头乌龟”行为的针对性剥离惩罚。

## 🎁 奖励函数设计与反思 (Reward Function)

强化学习的灵魂在于奖励函数。我们在奖励函数中融入了实盘交易的真实痛点：

### 1. 基础奖励：真实组合收益率
奖励的核心基座是组合的**净值对数收益率 (Log Return)**。区别于简单的平均涨幅，这里严格计算了每天扣除买卖手续费与滑点后的真实净值变化。

### 2. 双重紧箍咒：惩罚项的平衡
*   **换手率惩罚 (Turnover Penalty)**：对每天的买卖金额施加额外的负向奖励。
    *   *陷阱反思 (Collapse to Zero)*：如果惩罚过重，模型会觉得“多做多错”，为了不被扣分，它会把所有的 Action 输出为 0 或触发阈值，彻底拒绝交易，只拿底仓装死。
*   **最大回撤惩罚 (Drawdown Penalty)**：当净值从高点回落超过一定阈值时，给予严厉的扣分。
    *   *陷阱反思 (Collapse to Max)*：如果为了追求超额收益而剥除所有惩罚（处于无摩擦的温室），模型会发现永远顶格满仓、买最靠前的股票是理论上的最优解。Action 方差全部变为 0，失去了动态调节的意义。

**最终结论**：对于多因子驱动的强化学习，适当的罚金与惩罚机制是保持模型“灵动性”与“规避过度贪婪”不可或缺的边界。

## 🛡️ 架构规范与物理隔离

1. **训练与回测物理隔离**：严禁将模型训练（Training）与评估出图（Evaluation）糅合在同一个脚本中，规避评估阶段的环境越界截断问题（Off-by-One Error）。
2. **极速矩阵化（Vectorization）**：环境步进 `step()` 必须使用纯 Numpy 布尔切片，禁止在循环内使用 Pandas 操作，确保训练速度。
